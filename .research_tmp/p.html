This is a new section aiming at listing game specific file formats, other than game resource archives.
Thus, this includes sounds, textures, pictures, scripts, code and everything else, i.e. game resource formats (GRF)!

If you have specific information about a GRF, add a new entry to the list and edit the new page. Note that on the games' page you should separate by type. E.g. Textures, Sounds etc. Meanwhile we need to think of a calling convention for this new section, along with categories and so forth.
